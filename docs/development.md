# 协作开发

main仅接收审核并通过检查的变更。业务模块使用独立分支，PR列问题、变化、验证及未完成项。不强推main。锁定文件包含开发测试依赖；依赖更新需同步清单和锁定文件。Supabase连接池总连接数要按进程数核算。数据库迁移先在独立开发项目测试，禁止启动时自动迁移。


## 前后端并行启动

1. 按 backend/README.md 启动后端，监听 127.0.0.1:8000。
2. 按 frontend/README.md 安装依赖并启动前端，访问 127.0.0.1:5173。
3. 首页服务状态来自真实 /health；数据库未配置不影响此检查。
4. 业务开发按 contracts/openapi.json 协同增加接口与类型；目前只有健康检查接口。

前端代码通过 npm run build 后提交。修改依赖时同步 package-lock.json，其他成员和 CI 使用 npm ci。新增页面先在 src/pages 建目录，再在 src/app/App.tsx 登记路由。部署时将前端静态文件和后端服务分别配置，并为页面深链接配置 index.html 回退。
